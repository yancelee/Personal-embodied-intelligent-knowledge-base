# Tele\-Catch：自适应遥操\+Diffusion

**论文：**Tele\-Catch: Adaptive Teleoperation for Dexterous Dynamic 3D Object Catching

**作者：**Weiguang Zhao, Junting Dong†, Rui Zhang†, Kailin Li, Qin Zhao, Kaizhu Huang

**机构：**University of Liverpool, Shanghai AI Lab, Zhejiang University, Xi'an Jiaotong\-Liverpool University \(XJTLU\), Duke Kunshan University

**核心产物：**面向灵巧手动态接物的共享自主遥操作框架

**主要链接：**[论文](https://arxiv.org/abs/2603.28427)；代码；项目主页

# 一句话总结

**Tele\-Catch 把"人类戴手套的遥操作"和"学出来的扩散策略"融合成一个共享自主（shared autonomy）框架，让灵巧手能稳稳接住运动中的 3D 物体**——核心是两个模块：按物体动态自适应调节融合权重的 **DAIM**，以及引入无监督点云几何表征的 **DP\-U3R**。

# 研究问题

大多数灵巧手遥操作研究都盯着静止物体（抓握、手中操作）。但真实场景里大量任务涉及动态物体（自由下落、被抛来的物体），这类"实时接物"长期被忽视。

纯遥操作（手套动作直接映射给机械手）在动态接物上会翻车，原因有四类（见图 1）：

- 时机敏感：差几十毫秒就接空；

- 姿态估计难：物体飞太快，难以可靠感知可抓的接触构型；

- 力控制难：力小了打滑、力大了把物体弹飞；

- 映射误差：人手和机械手结构不匹配，快速运动下误差被放大。

本文要回答：**能不能把人类遥操作信号"灌进"一个学出来的策略里，用策略的稳定性去补偿人的时机/力度/映射误差，从而实现稳健的动态接物？**

# 核心方法

整体是一条"先在仿真里学、再在遥操作里用"的四阶段流水线（图 2）：

- \(a\) 训 RL 策略：用 PPO 在仿真里学一个稳定的动态接物策略（提供"老师"）。

- \(b\) 数据采集：用训好的 RL 策略成规模地生成 \(状态, 点云, 动作\) 轨迹，并用质量函数 Q\(τ\) 过滤掉失败样本。

- \(c\) 训 DP\-U3R：把这些数据拿来训练带无监督点云表征的扩散策略。

- \(d\) 遥操作执行：用 DAIM 把手套信号注入扩散去噪过程，按物体动态自适应地平衡"机器人稳定"与"人想怎么动"。

## RL 奖励与数据质量门

复合奖励（公式 3）：

$R = \lambda_{dist}R_{dist}+\lambda_{rot}R_{rot}+\lambda_{ftip\text{-}dist}R_{ftip\text{-}dist} - \lambda_{drop}P_{drop} - \lambda_{lin}P_{ftip\text{-}linvel} - \lambda_{ang}P_{ftip\text{-}angvel} - \lambda_{act}P_{act} - \lambda_{torque}P_{torque} - \lambda_{power}P_{power}$

**公式直觉解读**：做对了（手靠近物体 $R_{dist}$、朝向对齐 $R_{rot}$、指尖贴住物体 $R_{ftip\text{-}dist}$）给奖励；做错了（物体掉落 $P_{drop}$、手指乱甩 $P_{ftip\text{-}linvel/angvel}$、动作太大/力矩/费电）给惩罚。各惩罚系数很小（如 $2e^{-4}$），主要起平滑的 regularization 作用，而非主导学习。具体系数见附录 Tab\. 6（λ\_dist=10, λ\_rot=0\.1, λ\_ftip\-dist=10, λ\_drop=1\.0 等）。

数据质量门（公式 5）：

$Q(\tau)=\mathbb{1}\big[\text{no\_drop}(\tau)\;\wedge\;\lVert p^{T}_{obj}-p^{T}_{palm}\rVert_2<\delta\big]$

**公式直觉解读**：只保留"没接掉 **且** 最后一帧物体离掌心够近"的轨迹，其余丢弃。相当于**数据清洗**——只让成功的示范进训练集，垃圾样本不污染扩散策略。δ 是预设距离阈值。

## 2\. DP\-U3R：无监督 3D 表征增强扩散策略（Stage c）

点云处理链（公式 6–7）：

$f_{i,t}=E(\tilde{p}_t);\qquad f^{g}_t=P\big(\{f_{i,t}\}^{M_p}_{i=1}\big)$

$z_t=A\big(\{f_{i,t}\}^{M_p}_{i=1},\,f^{g}_t\big)$

**公式直觉解读**：先给点云故意加高斯噪声 $\tilde{p}_t=p_t+\xi_t$（自监督式数据增强，逼编码器学鲁棒特征）；编码器 $E$ 吐出**逐点特征** $f_{i,t}$（每个点的局部描述）；池化 $P$ 汇总成**全局特征** $f^{g}_t$（整团点云的"主旨"）；注意力 $A$ 把局部\+全局融合成 $z_t$。为省算力，**只把全局特征 **$f^{g}_t$** 接进扩散策略的观测** $\tilde{s}_t=[s_t,f^{g}_t]$，但重建损失仍在逐点上逼出几何信息。

两个训练目标（公式 8–10）：

$L_{recon}=\frac{1}{M_p}\sum^{M_p}_{i=1}\lVert p_{i,t}-\hat{p}_{i,t}\rVert_2^2$

$L_{noise}=\mathbb{E}_{t,\epsilon_t\sim\mathcal{N}(0,I)}\big[\lVert\epsilon_t-\hat{\epsilon}_t\rVert_2^2\big]$

$L=\lambda_{recon}L_{recon}+\lambda_{noise}L_{noise}$

**公式直觉解读**：

- $L_{recon}$ 是"点云重建损失"——让编码器从加噪点云里还原出原几何，**不需要任何人工标注**就学到形状先验（无监督）。

- $L_{noise}$ 是标准扩散噪声预测损失（预测加进去的噪声 vs 真噪声）。

- 两者加权求和（λ\_recon=λ\_noise=1\.0），即"既要看得懂几何，又要会去噪出动作"。

## 3\. DAIM：动态感知自适应融合机制（Stage d，本文心脏）

融合规则（公式 11）——这是整个框架最关键的一步：

$\tilde{x}_k=\hat{x}_k+\alpha(k)\,(x^{ref}-\hat{x}_k)$

**公式直觉解读**：这是**凸组合/线性插值**。$x^{ref}$ 是手套映射出的"人类参考动作"，$\hat{x}_k$ 是扩散策略第 $k$ 步去噪出的"机器人动作"，$\tilde{x}_k$ 是最终执行的混合动作。把它想象成**调音台混音**：两个音轨（人声 \+ AI 伴奏）叠加，$\alpha(k)$ 是"人声音量旋钮"。$\alpha=0$ 纯听机器人，$\alpha=1$ 纯听人。关键好处是**平滑过渡**而非硬切换，避免控制抖动。

时间调度（公式 12）：

$\alpha(k)=\alpha_{max}\cdot\Big(1-\cos\frac{\pi k}{2K}\Big)$

**公式直觉解读**：当去噪步 $k$ 从 0 走到 $K$，$\cos(\pi k/2K)$ 从 $\cos0=1$ 降到 $\cos(\pi/2)=0$，于是 $(1-\cos(\cdot))$ 从 0 升到 1，$\alpha(k)$ 从 0 **平滑爬升**到 $\alpha_{max}$。直觉是"**先让 AI 打草稿，再让人来定稿**"：去噪刚开始（还全是噪声）几乎不掺人手，让扩散策略主导把动作塑形出来；越接近完成，人类指令权重越大。用余弦是为了保证**单调、平滑**，不会忽大忽小。

按物体动态自适应最大权重（公式 13–14）——这是 "Dynamics\-Aware" 的由来：

$\alpha_{max}=\text{sigmoid}(u_0-u),\qquad u=\beta_v\frac{\lVert v\rVert}{v_0}+\beta_\omega\frac{\lVert\omega\rVert}{\omega_0}$

**公式直觉解读**：$u$ 是"**物体现在有多疯**"的指标——线速度 $v$ 和角速度 $\omega$ 越大，$u$ 越大。$\text{sigmoid}(u_0-u)$ 意味着：**物体动得越快 → **$u$** 大 → **$\alpha_{max}$** 小 → 越少听人的、越多靠扩散策略保稳定**；物体慢下来 → $\alpha_{max}$ 大 → 人多掌控。生活类比就像**开车**：路面颠/车速快（动态大）时把方向盘更多交给"自动驾驶稳定系统"；车慢进平稳路段，你接管更多。

为什么 $\beta_\omega=0.1$ 设得远小于 $\beta_v=10$（论文 5\.5 节解释）：角速度在碰撞瞬间会**突变且难估，故意压低它的权重，避免控制器被噪声带偏。**超参固定为 $\beta_v=10,\beta_\omega=0.1,u_0=1.0,v_0=1.0,w_0=10$。

> 设计选择总结：余弦 \+ sigmoid 两个调度都保证单调平滑，使遥操作表现为"**稳定的条件引导**"而非"破坏性扰动"。

> 

# 主要结果

**主表（Tab\. 2，全类别成功率均值）**：纯遥操作 Tele\-Pure 仅 35\.3%（时机/力度/映射误差所致）；Tele\-Catch 提升到 **54\.7%**，在 Truck、Teapot 等动态物体上增益明显。

**去噪精度（Tab\. 3，动作噪声 MSE）**：DP\-U3R 在多数类别上误差低于标准 DP 和 DP3，且跨物体波动更小 → 去噪更稳、对几何/动力学更鲁棒。说明"更丰富的 3D 信息 → 更好的动作去噪"。

**骨干对比（Tab\. 4，Truck 单类）**：

|方法|SR|
|---|---|
|Open\-Loop RL（DexGraspNet 基线）|46\.7%|
|Tele\-Pure（纯遥操作）|33\.3%|
|Tele\-Catch\(DP\)|46\.7%|
|Tele\-Catch\(DP3\)|60\.0%|
|Tele\-Catch\(DP\-U3R\)|**73\.3%**|

→ 共享自主把纯遥操作从 33\.3% 一路拉到 73\.3%；更强的扩散骨干进一步提鲁棒性。

**Sim2Real（图 4/6）**：真实系统 = Xhand 左手 \+ Manus 手套 \+ RealSense 435 \+ UR 机械臂，用轻量 TrackerCSRT 做物体追踪。真实环境光、传感噪声、接触差异让挑战更严峻，故论文主张"先在仿真里压测，再上真实硬件"。

**泛化（Tab\. 5）**：

- *跨构型*：ShadowHand→LinkerHand\-L20（重新训练），Teapot 上 73\.3% vs 纯遥操作 40\.0%。

- *未见类别*（不重新训练）：Eraser/Telephone/Bottle 上持续优于直遥操作（如 Eraser 66\.7% vs 53\.3%）→ 有一定零样本泛化。

- 运动多样性来自 RL 数据采集（不止自由落体，如加初速度后 Teapot 66\.7%）。

**敏感性（5\.5 节）**：Teapot 上 β\_v∈\{1,10,20\}→\{60\.0,86\.7,86\.7\}%；β\_ω∈\{0\.05,0\.1,0\.15\}→\{66\.7,86\.7,86\.7\}%。β 过大→遥操作被过度压制→反应保守→接物变差。环指敏感性实验（图 8）直观展示：物体不稳定时机器人主要靠扩散策略稳住，物体被抓住进入稳定态后，手套指令才逐渐主导。

# 创新点

1. **开新方向**：首个系统研究"灵巧手遥操作 \+ 动态接物"的工作，超越静态抓握。

2. **DAIM（动态感知自适应融合）**：把手套信号注入扩散去噪，用"余弦步调度 \+ sigmoid 动态调度"实现**平滑、稳定**的人机协作，避免了像 DexterityGen 那样用**固定硬阈值**导致的突兀仲裁。

3. **DP\-U3R（无监督点云表征）**：把无标注的 3D 几何先验融进扩散策略，提升鲁棒与泛化；相比 DexterityGen **显式利用了视觉观测**来 grounding 去噪。

4. **实验扎实**：仿真 \+ 真实、多种灵巧手（ShadowHand 24\-DoF / LinkerHand 16\-DoF / Xhand）、未见物体类别都验证有效。

> 与最相关工作的差异（Tab\. 1）：DSA/Bi\-DexHands/DP3/DexterityGen 要么针对静态物体、要么无共享自主、要么单手型；Tele\-Catch 唯一同时具备"自适应共享自主 \+ 3D 感知 \+ 多手泛化 \+ 动态接物"。
> 
> 

# 局限性

- **仍是难任务**：薄而带尖边的物体（Ipod、Fish）角先触地、高冲量反弹，频繁接掉——人类在环动态接物远未解决。

- **Sim2Real 早期**：真实验证只是"尝试"，主实验在仿真（Isaac Gym）；真实光照/传感噪声/接触差异会更严重。

- **依赖重新训练做跨构型**：换机械手需重训策略，非免训练迁移。

- **未与 DexterityGen 定量比**：对方未开源代码，故只在机制层面做定性对比。

- **成功率绝对值仍不高**（均值 54\.7%），说明动态接物本身天花板还远。

# 研究启发

> 你以 "paper\_with\_idea" 方式收藏本文，下面几条可作为你自己的切入点：
> 
> 

- **共享自主的"何时信人、何时信 AI"** 是个通用课题。DAIM 的"物体越快→越信策略"可被推广到其他人机协作任务（如装配、手术遥操作），调度函数（余弦\+sigmoid）是可替换的设计旋钮。

- **把遥操作当"条件引导"而非"覆盖"** 的思路很妙：注入到去噪过程而非直接改动作，保留了扩散先验。可对比其他"把外部信号注入生成模型"的做法（如 classifier\-free guidance 的变体）。

- **无监督几何表征** 与"少量演示即泛化"是具身智能的共性痛点，DP\-U3R 的"只接全局特征省算力"是工程上值得借用的 trick。

- **可改进的空白**：① 角速度权重与碰撞鲁棒性；② 免重训跨构型（当前需 retrain）；③ 真实世界物体状态估计（论文自己也建议用 2D/3D 追踪）；④ 把"接住后稳定保持"做成更硬的约束。
